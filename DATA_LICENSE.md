# Data access, attribution, and redistribution

This repository contains **no Freddie Mac loan-level data** and no loan-level
predictions derived from it. Users must obtain the Single-Family Loan-Level
Dataset (SFLLD) directly from Freddie Mac's Clarity Data Intelligence portal and
accept the applicable terms themselves.

Official resources:

- Dataset: https://www.freddiemac.com/research/datasets/sf-loanlevel-dataset
- Clarity download portal: https://claritydownload.fmapps.freddiemac.com/CRT/
- General User Guide: https://www.freddiemac.com/fmac-resources/research/pdf/user_guide.pdf
- Terms and Conditions: https://capitalmarkets.freddiemac.com/crt/docs/pdfs/fre_terms_conditions_sflld.pdf

The repository's MIT license covers only original code and documentation. It
does not supersede Freddie Mac's terms. Do not commit raw, processed, sampled,
or predicted loan-level records. Aggregate charts and metrics should be reviewed
to ensure they cannot be used to reconstruct or identify source records.

Freddie Mac is the source of the SFLLD. Freddie Mac does not endorse this
project, and the project is not investment advice or an official securities
disclosure.
